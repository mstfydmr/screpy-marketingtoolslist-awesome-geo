# Contributing

Contributions are welcome — this field moves fast and links go stale quickly.

## Guidelines

- Check the resource isn't already listed.
- Add it to the most relevant section, keeping descriptions to one concise, original sentence explaining what it is and why it belongs.
- Prefer primary sources — official docs, original research, first-party tool pages — over aggregator or listicle articles.
- Avoid pure marketing pages with no substantive content.
- Keep the list in [alphabetical or logical order](readme.md) consistent with the surrounding entries in that section.
- One resource per pull request is easiest to review, but small batches of clearly related additions are fine.

## Adding an entry

1. Fork the repo and create a branch.
2. Add your entry in the appropriate section of [`readme.md`](readme.md), following the existing `[**Title**](url) — description.` format.
3. Open a pull request with a short note on why the resource belongs.

## Removing or updating an entry

If a link is dead, a project is abandoned, or a description is inaccurate, please open a pull request or issue — corrections are just as welcome as new additions.

By contributing, you agree that your contributions are released under the same [CC0 license](LICENSE) that covers this list.
